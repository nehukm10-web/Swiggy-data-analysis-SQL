## Swiggy Data Analysis

Swiggy Data Analysis Using SQL
📌 Project Overview
This project focuses on analyzing Swiggy's food delivery data using SQL (Structured Query Language) to extract meaningful business insights. The analysis explores customer behavior, restaurant performance, order trends, revenue patterns, and food delivery operations.

The main objective is to transform raw data into actionable insights that can help improve business decision-making, customer satisfaction, and operational efficiency in the food delivery industry.

🎯 Problem Statement
Food delivery platforms generate large amounts of data related to customers, restaurants, orders, food items, and transactions. However, analyzing this data effectively is essential to understand business performance and identify areas for improvement.

The key business problems addressed in this project are:

Identifying sales and order trends.
Understanding customer ordering behavior.
Evaluating restaurant performance.
Analyzing revenue and order distribution.
Identifying popular food items and customer preferences.
Understanding patterns that could help improve business operations.
